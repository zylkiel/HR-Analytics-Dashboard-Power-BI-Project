# Palmoria HR Analytics Dashboard | Power BI

An interactive HR Analytics Dashboard built in Power BI to analyze workforce trends, salary structure, gender distribution, employee ratings, and pay compliance across departments and regions.

This project transforms raw HR data into clear, actionable insights through interactive visuals, KPI cards, and comparative analysis dashboards. The report highlights salary patterns, gender representation, regional workforce distribution, and performance trends to support data-driven HR decisions.

## Key Insights

* Balanced gender distribution across the organization
* Salary gaps identified across departments and regions
* Workforce concentration varies by location
* Most employee ratings fall within the average and good categories
* Pay compliance analysis revealed employees below salary requirements

## Tools & Skills Used

* Power BI
* Power Query
* DAX
* Data Cleaning & Transformation
* Data Visualization
* HR Analytics

This project strengthened my ability to build interactive dashboards, create meaningful business insights, and communicate data effectively through visualization.
